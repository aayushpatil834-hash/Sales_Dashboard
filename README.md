# 📊 Madhav Ecommerce Sales Dashboard

## Project Overview

The Madhav Ecommerce Sales Dashboard is an interactive Power BI report designed to provide comprehensive insights into ecommerce sales performance across multiple cities, states, customers, categories, and payment methods. The dashboard enables users to monitor key business metrics, identify profitable segments, and make data-driven decisions through intuitive visualizations and dynamic filtering capabilities.

## Objective

The primary objective of this dashboard is to analyze sales, profit, quantity sold, and customer purchasing behavior. By consolidating business data into a single interactive report, stakeholders can quickly identify trends, evaluate performance, and uncover opportunities for growth.

## Key Features

* 📈 Real-time analysis of sales, profit, and order quantity.
* 🌍 Interactive filtering by city and state.
* 👥 Customer-wise sales performance tracking.
* 📅 Monthly profit trend analysis.
* 🛒 Category-wise quantity distribution.
* 💳 Payment mode analysis to understand customer preferences.
* 📦 Sub-category profit analysis to identify high-performing products.

## Tools & Technologies Used

* 📊 Power BI Desktop
* 🔄 Power Query
* 🧮 DAX (Data Analysis Expressions)
* 🗄️ Data Modeling
* 📈 Interactive Visualizations


## 🎯 Project Goals

The primary goals of this project are:

* Analyze ecommerce sales performance across different regions and customer segments.
* Track key business metrics such as sales, profit, quantity sold, and average order value.
* Identify top-performing products, categories, and sub-categories.
* Understand customer purchasing patterns and payment preferences.
* Monitor monthly profit trends to detect seasonal variations.
* Enable data-driven decision-making through interactive visualizations and dashboards.
* Provide stakeholders with a centralized view of business performance.
